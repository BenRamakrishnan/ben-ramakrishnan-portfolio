# UI/UX Pro Max

## Core Standards
1. **Accessibility**:
   - Contrast minimum 4.5:1 for body copy and 3:1 for large display type.
   - Visible focus states on interactive elements.
   - Descriptive `aria-label`s on icon-only buttons.
2. **Touch & Interaction**:
   - Minimum target size 44×44px for primary mobile tap targets.
   - Tactile feedback: `active:scale-[0.98]` on buttons and cards.
3. **Typography & Hierarchy**:
   - Base font size 16px with line-height 1.5–1.6 for body.
   - Balanced line length (< 75ch).
