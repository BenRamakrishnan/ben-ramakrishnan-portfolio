# Design Taste Frontend Guidelines

## 1. Dials Configuration
- **DESIGN_VARIANCE**: 8 (High asymmetry, dynamic layout rhythm, avoid pure centered monotony)
- **MOTION_INTENSITY**: 6 (GPU-accelerated spring physics, fluid interactions, zero continuous CPU loops)
- **VISUAL_DENSITY**: 4 (Spacious, balanced breathing room, crisp visual hierarchy)

## 2. Anti-Default Discipline
- **No Cliché AI Gradients**: Banned multi-color neon text gradients (e.g. purple-to-cyan). Use neutral obsidian/slate bases with a singular, high-contrast accent (Signal Amber `#F59E0B` or Electric Cobalt `#3B82F6`).
- **No Monotonous Card Grids**: Never repeat the exact same card layout across multiple sections. Vary compositions using asymmetric Bento grids.
- **Eyebrow Restraint**: Maximum 1 eyebrow label per 3 sections.
- **CTA Discipline**: Button text must fit on one line at desktop. One label per intent.
- **No Continuous Canvas Loops**: Avoid CPU-intensive requestAnimationFrame particles. Prioritize CSS micro-textures and hardware-accelerated Framer Motion transitions.
