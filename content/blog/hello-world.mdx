Welcome to my new digital garden! 

I built this portfolio to act as a central hub for my projects, writings, and career history. The stack I chose for this iteration is deeply rooted in modern web standards and performance.

### The Stack

- **Framework**: Next.js 14+ App Router
- **Styling**: Tailwind CSS
- **Content**: MDX (Markdown + JSX)

### Why MDX?

MDX allows me to write in standard Markdown while seamlessly embedding interactive React components. This gives me the best of both worlds: the simplicity of authoring text and the power of React for rich experiences.
